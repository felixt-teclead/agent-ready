# Coding standards

Read this at code review. It applies to a human reviewer and to a reviewer agent.

## Testing

New or changed behaviour has a test. No coverage threshold.

## Review

Run typecheck and tests before you commit.

Do not change behaviour while you review. Change only how the code does it.

## Comments and documentation

Do not write a comment that repeats the code.

A reason that is true for one place stays a comment at that place. A reason that is true in two or more places goes in a doc section, and the comments point at that section.
